# Experimental-Design

Project Goal:

This repository contains two assignments. The aim of each was to practice basic experimental design methods using R programming language.

Description:

Assignment 1 - randomised design and factorial design.

Assignment 2.1 - fractional factorial design.

Assignment 2.2 - split-plot design.

Outputs:

All charts, summaries, tables, etc. can be viewed in [Assignment 1](docs/Assignment%201.pdf) and [Assignment 2](docs/Assignment%202.pdf)

How to Run:
1. Download or clone this repository to your computer.
2. Open RStudio and install the required packages:
   
    ```r
    install.packages(c("unrepx", "pid", "FrF2", "olsrr", "lmtest", "emmeans", "dplyr", "car"))
    ```
3. Open [`src/Assignment 1.R`](src/Assignment%201.R) or [`src/Assignment 2.R`](src/Assignment%202.R) and run the chosen script from top to bottom.
